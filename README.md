# フィンスト

2人対戦のブラウザゲーム。相手の両手をアウトにしたら勝ち。

**遊ぶ**: https://finstgame.github.io/

部屋を作って6文字のコードを相手に送るか、リンクを開いてもらえば始まります。
インストール不要。1台を回して遊ぶモードもあります。

ホーム画面に追加すると、アドレスバーの無い全画面で起動します（PWA）。
電波が無くてもCPU戦と1台版は遊べます。

## ルール

- おたがい 左手1本 / 右手1本 ではじまる
- **ちょうど5になった手はアウト**。5を超えたら5で割った余りに繰り下がる（3本の手に4 → 7 → 2本）
- 両手ともアウトで負け

自分の番にできるのは、次のどれか1つ。

| | |
| --- | --- |
| タッチ | 自分の手で相手の手をタップ。自分の本数が相手に足される |
| 分配 | 両手の合計を組み替える。0の手も復活できる。同じ配分・左右の入れ替えだけは不可 |
| カード | 手札から1枚使う |

能力カードは18種から3枚。各1回きりで補充なし。相手の手札は見えません。
「防御割り込み」のカードは相手に攻撃されたときに使い、15秒で自動パスになります。

## 構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 本体（フレームワークなしの素のHTML/CSS/JS） |
| `finst-phase1.html` | カードなしの初期版 |
| `manifest.webmanifest` | ホーム画面に置くための定義 |
| `sw.js` | オフライン用のサービスワーカー |
| `supabase/schema.sql` | オンライン対戦用のテーブル・RLS・Realtime設定 |
| `supabase/matchmaking.sql` | 野良マッチ（待ち行列） |
| `supabase/rating.sql` | レートとランク分け。`schema` → `matchmaking` → `rating` の順に実行する |

## レート

ランダム対戦だけレートが動きます（友達との部屋は動かない）。1200から始まり、
近いレートの人から順に当たります。相手が見つからないときは待つほど許容レート差が
広がり、最後はだれとでも当たります。

| レート | ランク |
| --- | --- |
| 1800〜 | マスター |
| 1600〜 | ダイヤ |
| 1400〜 | プラチナ |
| 1200〜 | ゴールド |
| 1000〜 | シルバー |
| 〜999 | ブロンズ |

計算はすべてデータベース側（`report_result`）で行います。クライアントが言えるのは
「この部屋を集計してくれ」だけで、**勝敗は関数が共有盤面（`matches.state`）を読んで決めます**。
負けた側が「勝った」と送っても通りません。決着していない盤面や、負けた側の手が
残っている盤面も弾きます。1部屋につき1回しか記録しません。

残る穴は、共有盤面そのものを書き換えられることです（クライアントが state を書く構成のため）。
そこまで塞ぐには、手の正しさを検証する審判を Edge Functions に置き、
`matches` への書き込みを service_role だけに限る必要があります。

## オンライン対戦について

Supabase Realtime で対戦状態を同期しています。静的サイトなのでサーバー側の審判が存在せず、
クライアントが状態を書き込む構成です。**理屈上チートは可能**で、ルームコードを知っていれば
誰でもその対戦を読み書きできます。友達内で遊ぶ前提の割り切りです。
