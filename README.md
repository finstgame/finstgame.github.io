# フィンスト

指を使う対戦ゲーム「割り箸ゲーム（Chopsticks）」に能力カードを乗せた、2人対戦のブラウザゲーム。

**遊ぶ**: https://yamadagenki0526icloudcom-hash.github.io/finst/

- 部屋を作って6文字のコードを相手に送るか、リンクを開いてもらえば始まります
- 1台を回して遊ぶモードもあります
- インストール不要

## ルール

- 各プレイヤー 左手1本 / 右手1本 で開始
- 自分の手で相手の手をタッチすると、自分の本数が相手に加算される
- **ちょうど「法」の値になった手はアウト**（通常は5）。超えたら法で割った余りに繰り下がる
- 分配で両手の本数を組み替えられる（同じ配分・左右入れ替えのみは禁止）
- 両手ともアウトで負け
- 10種の能力カードから3枚が配られる。各カードは1回だけ

## 構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 本体（フレームワークなしの素のHTML/CSS/JS） |
| `finst-phase1.html` | カードなしの素の割り箸ゲーム（Phase 1 の原本） |
| `supabase/schema.sql` | オンライン対戦用のテーブル・RLS・Realtime設定 |

## オンライン対戦について

Supabase Realtime で対戦状態を同期しています。静的サイトなのでサーバー側の審判が存在せず、
クライアントが状態を書き込む構成です。**理屈上チートは可能**で、ルームコードを知っていれば
誰でもその対戦を読み書きできます。友達内で遊ぶ前提の割り切りです。
